Login Page Design 🔑
This repository contains the front-end code for a modern and responsive login page, designed with a clean user interface using HTML and CSS. It serves as a static template for user authentication forms, focusing on a polished look and feel.

✨ Features
Clean & Modern UI: A visually appealing layout with a focus on simplicity.

Email/Password Login: Standard input fields for user credentials.

"Login with Google" Integration (UI only): A dedicated button for potential social login integration, complete with an icon.

"Remember Me" Checkbox: For user convenience during login.

"Forgot Password?" Link: A placeholder for redirecting users to password recovery.

"Create an account" Link: For new user registration.

Responsive Base: Designed with relative units to adapt to various screen sizes (further refinement may be needed for full mobile optimization depending on specific breakpoints).

🛠️ Technologies Used
HTML5: For the page structure and content.

CSS3: For all styling, layout, and visual presentation.

Google Fonts (Roboto): Imported for a modern typeface (implied by font-family: Roboto, sans-serif; in CSS).

Images: icons8-google-48.png for the Google login button icon.

🚀 Getting Started
To get a local copy of this project up and running, follow these simple steps.

Prerequisites
Ensure you have a modern web browser installed (e.g., Chrome, Firefox, Edge, Safari).

Installation
Clone the repository:
If you haven't already, clone this repository to your local machine:

Bash

git clone https://github.com/Chandrabhan-Choudhary/Login-page.git
cd Login-page
Create the index.html file:
Save the provided HTML code into a file named index.html in the root of your project directory (Login-page/).

Create the styles.css file:
Save the provided CSS code into a file named styles.css in the same root directory (Login-page/).

Add the Google icon:
Place the icons8-google-48.png image file in the same root directory (Login-page/) as your index.html and styles.css files.

You'll need to obtain this icon. A common source is Icons8 or similar icon libraries.

🏃 Usage
To view the login page design:

Open the index.html file directly in your preferred web browser.

You can usually do this by double-clicking the index.html file.

Alternatively, drag-and-drop index.html into an open browser window.

Or, right-click index.html and select "Open with" -> your preferred browser.

This will display the static login page, showcasing the front-end design. Please note that the form fields are for visual presentation only and do not have any backend functionality for actual login or user management.
